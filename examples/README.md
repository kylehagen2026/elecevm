# Example: distribution-center electrical package

A synthetic project generated by `elecevm example` (seed 7). No real project,
client, contractor or ledger data appears here; every number comes from a seeded
random process in `src/elecevm/example.py`.

| File | What it is |
| --- | --- |
| `elecevm.toml` | project configuration: calendars, disciplines, two-basis budget, CO log, AC basis rules |
| `schedule.csv` | 22 activities across three disciplines (FE, FSS, TEL), statused at the data date 2026-09-05 |
| `jobcost.csv` | ~960 ledger lines in a Vista-style JC Detail export layout (phase, cost type, dates, hours, amount) |
| `jobcost_totals.json` | the totals "as printed" on the job-cost report, used to reconcile the pull (check 5) |
| `quantities.csv` | weekly field progress records per activity (milestones achieved, partial milestone progress, field percent) |
| `baseline.json` | the version-1 time-phased baseline built from the schedule and the estimated-basis budget |
| `status_log.jsonl` / `status_log.csv` | the locked status history, weeks 1–26 |
| `snapshot_wk26.json` | the full week-26 status snapshot (activities, disciplines, EAC methods, checks) |
| `wsr_wk26.html` | the Weekly Status Report for week 26 with the cost curve and manpower charts |

Regenerate and rerun with:

```
elecevm example --out examples/distribution-center
```

The story the data tells: facility electrical is running about 12 % over its labor
hours with Area 2 and Area 3 starting late, fire/security is on plan, and telecom
is slightly behind. The result at week 26 is SPI 0.91 / CPI 0.90, a statistical
EAC about $763 k over the estimated BAC, and a forecast crossing of the
contracted funding line in week 30.
